# VSVK Planning, lokaal gebruik

## Starten
1. Pak de zip uit.
2. Dubbelklik op `index.html`. De app opent in je browser (Chrome, Edge, Firefox of Safari).

## Let op
- **Lokale modus.** Buiten Claude is er geen gedeelde database. De app draait dan op voorbeeldgegevens en bewaart wijzigingen alleen in deze browser (localStorage). Bovenin staat "Lokale modus · alleen in deze browser".
- **Geen live data.** De gegevens van de gedeelde planning zitten niet in dit bestand.
- **Internet nodig voor enkele onderdelen.** Lettertypen (Google Fonts), PDF-export (jsPDF) en Excel-export (SheetJS) worden van internet geladen. Zonder verbinding werkt de planning wel, maar met standaardlettertypen en zonder die exports.
- **Eén browser, één bestandslocatie.** Wis je de sitegegevens van de browser of open je het bestand vanaf een andere map, dan zie je je lokale wijzigingen niet meer.
- **Bron.** Dit is een kopie van het artifact "VSVK Planning", gedeeld door een ander account. Het origineel blijft ongewijzigd.
